# antispam-bot

Антиспам-бот для группы обсуждения телеграм-канала (комментариев под постами).

## Возможности

- **Анти-ссылки:** сообщения от обычных пользователей со ссылками или @упоминаниями
  (включая скрытые гиперссылки и подписи к медиа, а также отредактированные сообщения)
  удаляются, автор банится навсегда. Администраторы не проверяются.
- **Капча для новичков:** на первое сообщение бот присылает простой арифметический
  вопрос с четырьмя кнопками. Верный ответ — пользователь больше не проверяется.
  Неверный ответ или таймаут (5 минут) — удаление его сообщений и бан навсегда.
  Прогресс сохраняется в SQLite: после рестарта бота прошедшие капчу не проверяются заново.
- **Уведомления:** о каждом бане бот пишет администратору в личку.
- **Разбан:** в уведомлении о бане кнопка «Разбанить», плюс команды `/banlist`
  и `/unban <user_id>` в личке бота — доступны только владельцу (`ADMIN_CHAT_ID`).
  Разбан убирает пользователя из чёрных списков всех наблюдаемых групп;
  при следующем сообщении он получит капчу заново.

## Стек

Java 21, Spring Boot 3, telegrambots (long polling), SQLite, Docker.

## Настройка

1. Создайте бота у [@BotFather](https://t.me/BotFather), получите `BOT_TOKEN`.
2. Добавьте бота в группу обсуждения канала и сделайте администратором с правами:
   - **удаление сообщений**;
   - **блокировка участников**.
3. Узнайте ID группы: отправьте в группе любое сообщение и откройте
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — в ответе найдите `chat.id`
   (отрицательное число вида `-100…`).
4. Узнайте свой `ADMIN_CHAT_ID` (например, через [@userinfobot](https://t.me/userinfobot)).
5. Скопируйте `.env.example` в `.env` и заполните.

## Запуск локально (нужен JDK 21+)

```bash
./mvnw test             # тесты
./mvnw spring-boot:run  # .env из рабочей директории подхватывается автоматически
```

`.env` читается при старте приложения (переменные реального окружения имеют
приоритет — ими можно точечно переопределять значения, например
`ANTISPAM_ENABLED=false ./mvnw spring-boot:run`).
`chmod 600 .env` — токен не должен быть читаем другими пользователями машины.

В Bazzite/Fedora JDK ставится в distrobox, отдельный `mvn` не нужен — используется `./mvnw`.

Локальный CI: перед push гоняются тесты и Docker-smoke. Включение хука:

```bash
git config core.hooksPath scripts/hooks
chmod +x scripts/hooks/pre-push scripts/smoke.sh
```

## Команды владельца (в личке бота)

Работают только от `ADMIN_CHAT_ID`, остальным бот в личке не отвечает:

| Команда          | Действие                                                     |
|------------------|--------------------------------------------------------------|
| `/start`, `/help`| справка                                                      |
| `/banlist`       | забаненные в наблюдаемых группах (id, username, чат, дата)   |
| `/unban <user_id>`| разбан во всех наблюдаемых группах                           |

Кнопка «Разбанить» в уведомлении о бане делает то же, что `/unban`.

## Развёртывание на VPS (Docker)

Пошаговая инструкция — подготовка Telegram-бота и группы, установка Docker,
запуск, обновление, бэкап БД, диагностика — в [DEPLOY.md](DEPLOY.md).

Кратко:

```bash
rsync -av --exclude='.git' --exclude='target' --exclude='data' --exclude='.env' ./ user@VPS_IP:~/antispam-bot/
cd ~/antispam-bot && cp .env.example .env && nano .env
docker compose up -d --build
docker compose logs -f             # убедиться, что «Long polling запущен»
```

Контейнер перезапускается автоматически (`restart: unless-stopped`),
БД лежит в named volume `antispam-data` (посмотреть файл: `docker volume inspect antispam-data`).

## Переменные окружения

| Переменная        | Описание                                        | По умолчанию |
|-------------------|--------------------------------------------------|--------------|
| `BOT_TOKEN`       | токен от @BotFather                              | —            |
| `BOT_USERNAME`    | username бота без @                              | —            |
| `ADMIN_CHAT_ID`   | Telegram ID админа для уведомлений               | —            |
| `GROUP_IDS`       | ID групп через запятую                           | —            |
| `CAPTCHA_TIMEOUT` | время на ответ капчи (формат Spring duration: `5m`, `30s`, `PT5M`) | `5m`         |
| `ANTISPAM_ENABLED`| `false` — не подключаться к Telegram (для тестов)| `true`       |
| `DB_URL`          | JDBC-строка SQLite                               | `jdbc:sqlite:antispam.db` |

## Архитектура

```
UpdateRouter ── message/edited_message ──► LinkModerationService ──► EnforcementService (бан→удаление→уведомить)
             │                                        ▲                      ▲
             │                                        └ LinkDetector (entities + regex)
             └── callback_query (группа) ──► CaptchaService (вопрос/ответ/таймаут) ──┘
              └── личка владельца / кнопка разбана ──► OwnerCommandsService ──► UnbanService
                                        ▲
                     CaptchaExpiryScheduler (каждые 30 c, с проверкой «в чате ли юзер»)
```

Состояние участников (`PENDING/PASSED/BANNED`) — таблица `participants` в SQLite
(схема: `src/main/resources/schema.sql`).

## Ручная приёмка (после деплоя, в тестовой группе)

- [ ] Новый пользователь пишет «привет» → появляется капча с 4 кнопками.
- [ ] Нажал верную кнопку → «✅ Принято», следующие сообщения не проверяются.
- [ ] Нажал неверную → его сообщение и капча удалены, пользователь забанен,
      вам пришло уведомление в личку.
- [ ] Не отвечал 5 минут → то же самое (бан + уведомление).
- [ ] Сообщение со ссылкой от обычного пользователя → удалено + бан + уведомление.
- [ ] Сообщение с @упоминанием канала → удалено + бан + уведомление.
- [ ] Отредактировал старое сообщение, вписав ссылку → удалено + бан.
- [ ] Администратор пишет ссылку → ничего не происходит.
- [ ] Прошедший капчу вышел и зашёл снова → капча не выдаётся (статус в БД).
- [ ] Участник вышел из группы до ответа на капчу → бан не выносится, сообщение капчи убрано.
- [ ] `/banlist` в личке бота → список забаненных; `/unban <id>` → разбан,
      участник может вернуться и снова получает капчу.
- [ ] Кнопка «Разбанить» в уведомлении о бане → сообщение меняется на «✅ Разбанен …».
